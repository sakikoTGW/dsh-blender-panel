# @local/dsh-blender-panel

侧栏「模型」页签：看模型、调光调材质、**点选元素生成可复制的定位引用**，用来指着模型让 agent 改。

## 用法

1. 打开右侧栏 →「模型」页签
2. 顶部下拉选择 `.blend`（列表来自 `E:\逆向` 下的 .blend，按修改时间排序）
3. 视图里：拖动旋转、滚轮缩放、右键平移
4. 顶部工具栏：
   - 视角：3/4 · 前 · 侧 · 后 · 顶
   - 灯光：棚拍 · 暖 · 冷 · 平光
   - 背景：黑底 · 灰底 · 白底 · 透明
   - 材质：贴图 · 黏土 · 线框
   - 选择（开/关）· 曝光滑杆 · 截图
5. **单击模型任意位置** → 底部显示该点信息（对象、面号、局部坐标、UV、材质），点「复制引用」得到一行文本：

```
E:\逆向\_hero\anon\anon_8k_clean.blend | mesh | 局部坐标 (0.012, 0.44, 0.973) | uv 0.312, 0.618 | face 123456 | 材质 tripo_material_...
```

把它贴给 agent，就能定位到你指的那一块。

## 结构

| 文件 | 作用 |
|---|---|
| `index.js` | Host 路由：`/files`（.blend 列表）、`/glb`（导出/缓存）、`/viewer`（视图页面）、`/assets/*` |
| `lib/viewer.js` | 视图页面：three.js 场景、工具栏、光照/材质/背景预设、射线拾取、与父页面 postMessage |
| `client.js` | 侧栏页签：文件选择 + iframe 视图 + 拾取结果显示/复制 |
| `addon/dsh_bridge.py` | （可选）Blender 内桥接：场景状态、选中、变换、Python、消息推送 |
| `native/*.ps1` | 早期"把 Blender 窗口嵌进侧栏"的实验代码，当前页签不再使用 |
| `lib/launcher.js` | 启动器只读体检与可选写入（当前不自动写） |

## 导出管线

`/glb` 用 Blender 后台模式导出：**不做修改器烘焙、不改法线、不压 Draco**（原样几何 + 原始 UV/贴图），
按源文件 mtime 缓存；换算法时改 `EXPORTER_VERSION` 让缓存整体失效。
